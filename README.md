# Nhật Ký Cấy Tóc

## Công nghệ sử dụng
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
- Next.js 16.4 (App Router, Turbopack): framework chính, trang bài viết sinh tĩnh lúc build
- React 19.3: xây dựng giao diện
- TypeScript 5: ngôn ngữ viết code
- Tailwind CSS v4: viết CSS, khai màu và font trong `src/app/globals.css`
- MDX (`@next/mdx`): mỗi bài viết là một file `.mdx` trong `src/content/posts/`
- Font Awesome 7: icon
- next/font: font Inter và Dancing Script (hỗ trợ tiếng Việt)
- next/image: tối ưu ảnh
- ESLint 9: kiểm tra code (`npm run lint`)
---
## Getting Started
```bash
npm install
npm run dev
```
